# Arduino Workshop

Stunden dieses Kurses werden als JSON-Datensätze im Unterordner `lessons/`
definiert. Die Klasse wählt sie anhand ihrer IDs in `class.json` aus.

## Dateien für den Lehrerbereich

Dateien und Ordner für Downloads kommen in den Unterordner `files/`. Sie
werden automatisch auf der Downloadseite der Klassen dieses Kurses angezeigt.
Die Datei `.gitkeep` hält den Ordner im Repository fest und wird nicht
angezeigt.
