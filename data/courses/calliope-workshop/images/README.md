# Stundenbilder: Calliope Workshop

Bilder, die in Stunden dieses Kurses verwendet werden, liegen in einem
Unterordner pro Stunde. In den Stunden-JSON-Dateien wird im Feld `image` der
relative Pfad innerhalb dieses Ordners angegeben, zum Beispiel
`erste-stunde/Download_1.png`. Die App liefert Bilder ausschließlich aus dem
`images/`-Ordner des Kurses der aufgerufenen Klasse aus.

Die Bilder der Beispielstunde liegen in [`erste-stunde/`](erste-stunde/) und
werden in [`lessons/erste-stunde.json`](../lessons/erste-stunde.json)
referenziert.
