# Calliope Workshop

## Verfügbare Stunden

Die Beispielstunde liegt als JSON-Datensatz im Unterordner `lessons/` und wird
in der Klasse anhand ihrer ID ausgewählt. Die zugehörigen HTML-Vorlagen liegen
unter `templates/lessons/`. Die kursbezogenen Bilder für Stunden kommen in
`images/`.

## Dateien für den Lehrerbereich

Dateien und Ordner für Downloads kommen in den Unterordner `files/`. Sie
werden automatisch auf der Downloadseite der Klassen dieses Kurses angezeigt.
Die Datei `.gitkeep` hält den Ordner im Repository fest und wird nicht
angezeigt.
